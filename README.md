# Expense Tracker 💰

A simple Java-based Expense Tracker application that helps users record, view, and calculate their expenses. This project demonstrates core Java concepts such as classes, objects, ArrayList, and user input handling.

## Features

* Add new expenses
* View all expenses
* Calculate total expenses
* Simple menu-driven interface
* Easy expense management

## Technologies Used

* Java
* ArrayList
* Scanner Class
* Object-Oriented Programming (OOP)

## Project Structure

```text
expense-tracker/
│
├── ExpenseTracker.java
└── README.md
```

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/expense-tracker.git
```

2. Navigate to the project folder:

```bash
cd expense-tracker
```

3. Compile the Java program:

```bash
javac ExpenseTracker.java
```

4. Run the application:

```bash
java ExpenseTracker
```
